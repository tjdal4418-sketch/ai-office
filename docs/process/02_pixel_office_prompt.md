# AI 오피스 — 픽셀아트 사무실 홈페이지 프롬프트

> 사용법: **5단계를 끝내고 6단계(마무리) 전에** "5.5단계"로 붙여넣으세요.
> 이미 만든 카드형 홈페이지는 그대로 두고, **탑다운 픽셀아트 사무실 화면을 새로 추가**하는 내용이에요.
> 참고 이미지가 있으면 클로드코드 창에 같이 붙여넣으세요.

```
5.5단계: 홈페이지에 픽셀아트 사무실 화면을 추가하고 싶어.
첨부한 이미지 같은 탑다운(위에서 내려다보는) 픽셀아트 사무실이야. 게더타운 같은 느낌이야.

## 0. 먼저 지켜줘 (이미 5단계까지 만든 상태야)
- 백엔드(상태·SSE·API·DB)와 에이전트 로직은 절대 수정하지 마. 프론트만 추가하는 작업이야.
- 기존 index.html(카드형)과 agent.html(상세 페이지)은 지우지 말고 그대로 둬.
  새 화면은 office.html로 만들고, 상단에 [🏢 오피스 뷰 | 📋 목록 뷰] 전환 버튼을 달아줘.
  다 만든 뒤 내가 확인하면 오피스 뷰를 기본 홈으로 바꿀 거야.
- 시작 전에 지금 프로젝트 구조, 상태값 이름, SSE 이벤트 형식, 승인/반려 API,
  매니저의 "월마감 시작" 흐름을 먼저 읽고 요약해줘. 새 화면은 그 데이터를 그대로 써야 해.
- 사이드 패널의 업로드·다운로드·승인/반려는 새로 만들지 말고 기존 agent.html 기능(API)을 재사용해줘.

## 1. 기술 방식
- HTML5 Canvas 2D + 바닐라 JS (빌드 도구 없이 동작)
- 타일 크기 16px 또는 32px, 정수배 확대, imageSmoothingEnabled = false (픽셀이 흐려지지 않게)
- 화면 크기에 맞춰 캔버스를 정수배로 스케일링
- 그래픽 에셋: 저작권 문제를 피하려고 외부 이미지를 쓰지 않고 JS 코드로 직접 픽셀을 그려줘
  (바닥, 벽, 책상, 의자, 모니터, 책장, 소파, 화분, 정수기, 복합기, 캐릭터 전부).
  나중에 CC0 에셋(예: Kenney)으로 바꿀 수 있게 "스프라이트 그리는 함수"를 한 파일(sprites.js)에 모아줘.
- 파일 구성: static/office/ 아래 map.js(맵·가구 배치), sprites.js(그리기), agents.js(캐릭터 움직임),
  ui.js(말풍선·패널), main.js(게임 루프, SSE 연결)

## 2. 사무실 맵 (가구에 업무 의미를 붙여줘)
| 위치 | 가구 | 의미 |
|---|---|---|
| 위쪽 가운데 | 매니저 데스크(유리 칸막이) | 📁 매니저 자리 |
| 왼쪽 중간~아래 | 책상 4개(모니터 포함) | 💰페이 📒북키 🧾배트 🏛️코택 자리, 책상 앞에 이름표 |
| 왼쪽 위 | 회의 테이블 + 의자 6개 | "고객사 월마감 시작" 때 다 같이 모이는 곳 |
| 위쪽 벽 | 화이트보드 | 클릭하면 신고기한 D-day 캘린더 |
| 위쪽 벽 | 책장 | 클릭하면 rules(세율·요율 근거) 목록 = "법령 자료실" |
| 위쪽 벽 | TV | 클릭하면 실시간 활동 로그 |
| 오른쪽 위 | 탕비실(흰 타일, 정수기, 커피머신) + 복합기 | 대기 중 캐릭터가 들르는 곳 / 결과 파일이 나오면 복합기에서 종이 출력 애니메이션 |
| 오른쪽 아래 | 라운지(카펫, 소파, 원형 테이블, 화분) | 대기중 캐릭터가 쉬는 곳 |
| 아래쪽 가운데 | 출입문 | 장식 |
| 창문 | 왼쪽 위 | 실제 시각에 따라 낮/저녁 색 바뀌면 좋음(선택) |
가구에 마우스를 올리면 커서가 바뀌고 툴팁이 뜨게 해줘.

## 3. 캐릭터 = 에이전트 상태 표현
캐릭터 5명은 각자 머리색·옷 색을 다르게, 머리 위에 이름표(💰페이 등)를 띄워줘.
상태가 SSE로 바뀌면 캐릭터가 걸어서 이동한다 (타일 그리드 A* 길찾기, 4방향 걷기 애니메이션 2~3프레임).

- 🟢 대기중: 라운지 소파에 앉거나, 탕비실·라운지를 천천히 돌아다님. 가끔 "☕" 말풍선
- 🔵 일하는중: 자기 책상으로 걸어가 앉음. 모니터 화면이 켜지고 깜빡임, 타이핑 모션.
  머리 위 말풍선에 현재 단계 + 진행률 바 (예: "급여 계산 18/32명 ▓▓▓░░ 56%")
- 🟡 검토필요: 책상에서 일어나 매니저 데스크 앞(또는 자기 자리)에서 노란 "!" 말풍선이 통통 튀는 애니메이션.
  클릭하면 검토·승인 패널 열림
- ✅ 완료(승인 후): 복합기에서 종이 나오는 효과 → 초록 "✔" 말풍선 2초 → 라운지로 이동(대기중)
- 🔴 오류: 책상에서 모니터가 빨갛게 변하고, 빨간 "!" 말풍선 + 오류 사유 한 줄 (예: "주민번호 누락 2건")
- 매니저가 "월마감 시작"을 누르면 다 같이 회의 테이블로 모였다가 각자 자리로 흩어지는 연출(선택)

## 4. 화면 UI
- 캐릭터 클릭 → 오른쪽 사이드 패널: 담당업무, 현재 상태, 진행률, 최근 작업 이력, 파일 업로드, 결과 다운로드, 승인/반려 버튼
- 상단 바: "AI 오피스" 로고, 날짜·시계, 신고기한 D-day 배지, 오늘 처리/검토대기/오류 건수
- 하단: 활동 로그 한 줄 티커 (TV와 같은 데이터)
- 픽셀 폰트: Google Fonts의 "Galmuri"가 안 되면 "DotGothic16" 또는 "Press Start 2P" + 한글은 기본 고딕
- 색감: 따뜻한 원목 바닥, 남색 벽, 부드러운 파스텔 — 참고 이미지 분위기

## 5. 꼭 지켜줘
- 데모 버튼(상단 오른쪽 "▶ 데모")을 누르면 5명이 순서대로 일하는중→검토필요→완료→대기중을 도는 시연 모드
  (포트폴리오 GIF 녹화용)
- 60fps 게임 루프지만 탭이 안 보일 땐 멈추게(requestAnimationFrame)
- 모바일(가로 768px 미만)에서는 기존 카드형 index.html로 자동 이동
- 캔버스는 스크린리더가 못 읽으니, 상태 목록을 숨김 텍스트(aria-live)로도 제공

## 진행 순서
1) 맵·가구만 먼저 그려서 보여줘 → 내가 배치 확인
2) 캐릭터 + 걷기 + 길찾기
3) 상태별 연출 + SSE 연결
4) 사이드 패널·툴팁·데모 모드
각 단계 끝날 때마다 멈추고 확인 방법을 알려줘.
```
